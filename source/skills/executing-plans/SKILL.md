# Execute an Existing Plan

Read the plan and relevant repository instructions. Reuse established requirements
and authorization; ask only about gaps that materially affect the outcome.
Resolve routine details from the code and project conventions.

Track the tasks with the environment's available planning tool. Work in dependency
order, keep changes focused, and run each task's relevant checks. Revise the plan
when evidence changes the approach, explaining consequential changes.

Honor review checkpoints requested by the user or plan. Otherwise continue through
independent authorized work without adding approval stops. Investigate routine
failures; report a blocker when progress needs missing information or access.

Use `verification-before-completion` for completion evidence and `update-readme`
for documentation. Report the result, checks, and unresolved work. Commit, push,
merge, or deploy only within the user's and repository's authorization.
