# Five Whys

Read [the shared Five Whys technique](../systematic-debugging/five-whys.md)
relative to this skill directory. It applies to coding and noncoding problems;
using it does not require the full systematic-debugging workflow.

Honor analysis-only requests: investigate and recommend without changing files,
adding diagnostics, implementing fixes, or performing other mutations. Keep the
question count and reporting depth proportional to the problem.

Both skill folders ship together. If the reference is missing, report the missing
file and ask for both folders to be restored or updated together; do not invent
its contents or install anything without authorization.
