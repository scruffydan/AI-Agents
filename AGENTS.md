# Project scope

This is a small personal project. Downtime is acceptable, and simplicity comes
first. Prefer focused changes and the simplest adequate solution. Personal use
does not imply that data loss is acceptable.

Edit shared content in `source/` and harness settings in `renderers.py`.
`build/` is generated by `./build.py`.
Test with `python3 -m unittest discover -s tests` (Python 3.11+).
Skills are copied unchanged to every harness: keep them portable
(name + description frontmatter only, no harness-specific tool names).

When removing or renaming a shipped agent or skill, update `install.py` in the
same change so the installer can move old installed copies into its backup
folder. Keep retirement entries so users who skip releases still get the cleanup.
