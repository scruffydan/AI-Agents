# Project scope

This is a small personal project. Downtime is acceptable, and simplicity comes
first. Prefer focused changes and the simplest adequate solution.

Edit `source/` and `templates/`; `build/` is generated by `./build.py`.
Test with `python3 -m unittest discover -s tests` (Python 3.11+).
Skills are copied unchanged to all three harnesses: keep them portable
(name + description frontmatter only, no harness-specific tool names).
